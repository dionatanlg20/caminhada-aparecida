# Caminhada a Aparecida

App para acompanhar a caminhada até o Santuário Nacional de Aparecida. Abre no navegador do celular e pode ser instalado na tela inicial.

- **Painel:** distância até o Santuário, progresso, km andados, tempo e próxima parada.
- **Mapa:** percurso e sua posição pelo GPS.
- **Etapas:** percursos São Paulo → Aparecida, Rio → Aparecida ou a partir da sua localização.
- **Checklist:** itens da mochila e dicas de segurança.

Os dados ficam salvos só no próprio celular.
